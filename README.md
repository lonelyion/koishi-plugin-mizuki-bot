# mizuki-bot

✨ 明日方舟水月主题多功能 BOT ✨

[![npm](https://img.shields.io/npm/v/koishi-plugin-mizuki-bot?style=flat-square)](https://www.npmjs.com/package/koishi-plugin-mizuki-bot)

## 功能

### 🪼 水母箱 & 深海厨房
- `水母箱`：查看个人水母箱（含温盐度状态），并结算离线繁殖与随机事件
- `水母箱.抓水母`（别名 `抓水母`）：每 2 小时可抓一次水母
- `水母箱.投喂 [暖汤|冰沙|秘制]`（别名 `投喂` / `喂水母`）：消耗深海食材让水月为水母箱烹制料理，调节温盐度并触发繁殖/吸引/减冷却等趣味事件
- `水母箱.统计`（别名 `水母统计表`）：查看箱内各类水母数量统计
- `水母箱.图鉴`（别名 `水母图鉴`）：查看全量水母图鉴
- `水母箱.样式 <normal|pixel>`（别名 `样式`）：切换默认/像素水母绘制样式
- `水母箱.放生 <名称|ID|稀有度> [数量|all]`（别名 `放生`）：放生指定数量的水母或整组稀有度水母

### 🎮 明日方舟互动游戏 & 每日运势
- `猜干员 [-s|-H]`（别名 `干员猜谜` / `方舟猜谜` / `wordle`）：干员属性推理 Wordle，支持群内直接发送干员名或 `猜 <干员名>` 全群协作推理（比对星级、职业、分支、阵营）
- `猜干员.立绘`（别名 `立绘猜干员`）：看局部立绘猜明日方舟干员
- `今日运势`（别名 `运势` / `水月运势` / `抽签`）：抽取每日水月肉鸽风味运势签（灯火值、守护干员、藏品、宜忌），首签自动赠送深海食材并缩减抓水母冷却

### 👤 昵称
- 平台昵称会自动同步（包括 QQ 官方机器人 API v2 的用户昵称与群名片，无需手动注册）
- `叫我 [昵称]` / `叫我 -r`：可选自定义称呼或重置回自动同步

## 开发与测试

```bash
npm run build      # 编译产物与类型声明
npm run lint       # ESLint 检查
npm test           # 运行 Vitest 单元测试与集成测试
npm run dev        # 在 ../koishi-app 中启动开发调试环境
```
